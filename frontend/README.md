# Smart Traffic Management System - Frontend
## Setup
```bash
npm install
npm start
```
## Available Scripts
- \
pm start\ - Runs the app in development mode
- \
pm build\ - Builds the app for production
- \
pm test\ - Launches the test runner
## Components
- Dashboard - Statistics and overview
- UploadVideo - Video upload interface
- Violations - Violation management
- Drivers - Driver management
- RegisterDriver - New driver registration
- PaymentPage - Payment processing
## Tech Stack
- React 18.2.0
- React Router DOM
- Axios
- Stripe React
