# 🚦 Smart Traffic Management System
A comprehensive B.Tech project for automated traffic violation detection and management.
## 🎯 Features
- ✅ Video upload and processing with OpenCV
- ✅ Vehicle detection with bounding boxes
- ✅ License plate recognition using Tesseract OCR
- ✅ Automated email notifications with evidence
- ✅ Online payment via Stripe
- ✅ Driver registration and management
- ✅ Violation tracking and history
- ✅ Real-time dashboard with statistics
## 🛠️ Tech Stack
**Backend:** FastAPI, MongoDB, OpenCV, Tesseract OCR, Stripe  
**Frontend:** React.js, React Router, Axios, Stripe React
## 📦 Quick Start
### Backend Setup
```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
# Edit .env with your credentials
python main.py
```
### Frontend Setup
```powershell
cd frontend
npm install
npm start
```
